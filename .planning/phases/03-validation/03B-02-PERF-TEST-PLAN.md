### 步骤 2: 运行性能测试

**测试方法**: 微基准测试

**测试项目**:
1. **函数调用性能** (1M iterations)
   - 测试 JIT 对函数调用的优化
   - LTO 应该能内联更多函数

2. **循环性能** (1M iterations)
   - 测试 JIT 对循环的优化
   - LTO 应该能优化循环结构

3. **列表操作** (100K iterations)
   - 测试 JIT 对数据结构的优化
   - LTO 应该能优化内存访问

**测试环境**:
- 独立虚拟环境 (避免污染)
- 相同的 Python 版本
- 相同的系统环境
- 多次运行取平均值

---

### 步骤 3: 性能对比分析

**计算方法**:
```
性能提升 = ((baseline_time / lto_time) - 1) * 100%
```

**目标**:
- ✅ 平均性能提升: **+5%~+10%**
- ✅ 无退化: **<1%**
- ✅ 单项最低: **>3%**

**预期结果**:
- 函数调用: +6%~+12% (内联优化)
- 循环: +4%~+8% (循环展开)
- 列表操作: +5%~+10% (内存优化)
- **平均: +5%~+10%**
